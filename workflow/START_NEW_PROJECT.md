# Start New Project

建立新產品時，請依序完成：

1. 建立獨立產品 Repo。
2. 複製本 Repo 的必要模板。
3. 完成 `PROJECT_BRIEF.md`。
4. 盤點現有技術棧與既有程式。
5. 建立 `ARCHITECTURE.md`。
6. 建立 `DECISIONS.md`。
7. 建立 `PROJECT_STATUS.md`。
8. 建立 `NEXT_SPRINT.md`。
9. 建立 `KNOWN_ISSUES.md`。
10. 建立 `.env.example`。
11. 確認本機啟動方式。
12. 確認部署方式。
13. 才開始第一個功能。

不得在文件與現況未釐清前要求 Codex 直接大改程式。
