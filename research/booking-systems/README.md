# Open Source Booking Systems Research

This folder records reusable product and architecture lessons from open-source booking and appointment systems. It is research material only. Do not copy product code into `aiwe-dev-system`.

## Scope

| File | Focus | Primary lesson |
| ---- | ----- | -------------- |
| `EASY_APPOINTMENTS.md` | Self-hosted appointment scheduler | Simple service-provider-customer booking flow |
| `LIBREBOOKING.md` | Resource reservation platform | Resource-first reservation, quotas, roles, waitlists |
| `CAL_DIY.md` | Self-hosted scheduling infrastructure | Event-type availability and integration-heavy booking |
| `THUNDERBIRD_APPOINTMENT.md` | Calendar appointment link service | Subscriber availability plus public booker page |
| `BOOKING_SYSTEM_COMPARISON.md` | Cross-system comparison | What to reuse as patterns, not code |

## AIWE Usage Rule

Use this research to design SaaS booking journeys, tenant boundaries, acceptance tests, and domain models. It is not permission to merge product code, migrations, or vendor-specific assumptions into this repository.
